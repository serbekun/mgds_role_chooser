# MGDS Role Chooser

[English](README.md) | Русский

Discord-бот на Rust, который публикует на сервере Maxim Games Discord Server панели с кнопками для самостоятельной выдачи и снятия ролей.

Каждая панель — сообщение **«Выберите себе роль:»** с кнопками (по 5 в ряд). У панелей могут быть разные роли, а одна панель может публиковаться в нескольких каналах. Нажатие выдаёт роль, повторное нажатие снимает её; ответ виден только нажавшему.

## Возможности

- Панель с кнопками для выдачи/снятия ролей.
- Переключение роли по повторному нажатию.
- Эфемерные ответы с результатом операции.
- Логирование через `tracing`.
- Роли и каналы публикации задаются вместе в `config.yaml`, поэтому их можно менять без пересборки бота.

## Требования

- Rust 1.85+ (проект использует edition 2024).
- Discord-приложение с ботом и его токен.

## Настройка Discord

1. Создайте приложение на [Discord Developer Portal](https://discord.com/developers/applications).
2. На вкладке **Bot** получите токен.
3. Привилегированные intents (Server Members, Message Content) не требуются — бот использует только `GUILDS`.
4. Пригласите бота на сервер со scope `bot` и правами:
   - **Manage Roles** — для выдачи и снятия ролей;
   - **View Channels** и **Send Messages** — для публикации панели в целевом канале.
5. Роль бота должна находиться **выше** всех ролей, которыми он управляет. Иначе Discord вернёт ошибку при попытке выдать роль.

## Конфигурация

Бот настраивается через переменные окружения:

| Переменная | Обязательна | Описание |
| --- | --- | --- |
| `MGDS_ROLE_CHOOSER_TOKEN` | Да | Токен Discord-бота. Не коммитьте его в репозиторий. |
| `MGDS_ROLE_CHOOSER_CONFIG_PATH` | Нет | Путь к YAML-конфигу ролей и каналов. По умолчанию `config.yaml`. |

Если у панели пустой `channel_ids`, она не публикуется. Если `MGDS_ROLE_CHOOSER_CONFIG_PATH` не задан, бот читает `config.yaml` из текущей рабочей директории.

> **Важно:** панели отправляются во все указанные каналы при **каждом** запуске. Чтобы не создавать дубликаты, уберите ID каналов после публикации. При ошибке отправки бот прекращает рассылку и продолжает запуск. После перехода на новый формат удалите старые сообщения и опубликуйте панели заново.

## Запуск

```bash
export MGDS_ROLE_CHOOSER_TOKEN="ваш_токен"
# Необязательно: по умолчанию используется ./config.yaml
export MGDS_ROLE_CHOOSER_CONFIG_PATH="config.yaml"

cargo run --release
```

Сборка без запуска:

```bash
cargo build --release
```

Готовый бинарник появится в `target/release/mgds_role_choosier`.

## Добавление и изменение ролей

Список панелей, каналы и роли задаются в `config.yaml`:

```yaml
panels:
  - id: games                         # постоянный уникальный ID панели
    channel_ids:                      # панель отправится в каждый канал списка
      - 123456789012345678
      - 234567890123456789
    roles:
      - label: Minecraft
        custom_id: role_minecraft     # уникален внутри этой панели
        role_id: 1073194781984952431
  - id: interests
    channel_ids: []
    roles:
      - label: Игры
        custom_id: role_minecraft     # повторы между панелями разрешены
        role_id: 1072840854806470727
```

Чтобы добавить роль:

1. Добавьте новую панель в `panels` с постоянным уникальным `id`, собственными `channel_ids` и `roles`.
2. Добавьте ID каналов, куда нужно отправить панель. Один список может содержать несколько каналов.
3. `custom_id` ролей должен быть уникальным внутри панели; одинаковые значения в разных панелях допустимы.
4. Перезапустите бота — пересборка не требуется. Старые сообщения не обновляются автоматически.

Бот проверяет конфиг при старте и не запускается, если:

- список панелей пуст, ID панели повторяется или содержит недопустимые символы;
- список ролей панели пуст или содержит больше 25 ролей (ограничение Discord на одно сообщение);
- `custom_id` пустой или повторяется внутри панели;
- итоговый ID кнопки длиннее 100 символов;
- ID канала равен `0` или повторяется в одной панели;
- `label` пустой или длиннее 80 символов;
- `role_id` равен `0`.

Сохраняйте `id` панели неизменным, чтобы её кнопки продолжали работать после перезапуска. Если удалить панель или изменить её `id`/`custom_id`, старые кнопки перестанут обрабатываться — опубликуйте новую панель.

## Структура проекта

```
src/
├── main.rs      # запуск, чтение конфигурации, отправка панели при старте
├── handler.rs   # обработка нажатий на кнопки и переключение ролей
└── roles.rs     # загрузка/проверка ролей и сборка панели с кнопками
config.yaml      # конфигурация ролей и каналов публикации
```

## Логи

Бот пишет логи в stdout на уровне `INFO`. Ошибки Discord API (нехватка прав, неудачная выдача роли и т.п.) логируются через `tracing::error!`, а пользователю приходит понятное сообщение в ответе на нажатие.
